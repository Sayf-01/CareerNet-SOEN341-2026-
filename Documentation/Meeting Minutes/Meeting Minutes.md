## 3. Discussion Summary

**Overall project progress:** The team reviewed the ongoing work and how the different features connect. Members shared updates on their assigned tasks, pull requests, dependencies, and areas that still need checking before the Sprint 3 demonstration.

**Recruiter dashboard and applications:** We discussed managing job postings, editing and archiving jobs, viewing applicants, changing application statuses, setting interview dates, and opening applicant resumes. We also reviewed how the frontend uses the backend APIs for these actions.

**Application analytics and notifications:** We went over the application history and analytics dashboard, including application counts and status information. We also discussed notifications for application updates, interview scheduling, and related recruiter activities.

**AI resume feedback:** We reviewed the resume feedback feature, including uploading resumes, requesting feedback, displaying results, and connecting the frontend to the feedback endpoint. We also discussed handling errors and keeping API keys and resume data protected.

**Testing and integration:** We discussed unit tests, GitHub CI checks, and the need to verify complete user flows after individual components are merged. The team identified final end-to-end acceptance testing as an item to confirm rather than assuming that passing CI proves the entire application works together.

**Documentation and demo preparation:** We reviewed the GitHub project board, contribution logs, AI usage logs, personal Sprint 3 reports, meeting minutes, and the team summary. We also discussed preparing a clear demonstration of the main features and making sure each member can explain their contribution.

## 4. Decisions and Outcomes

- Continue using GitHub issues, branches, pull requests, and reviews to track project work.
- Keep the team focused on integration checks, unresolved issues, documentation, and demo preparation.
- Record final test results only after the relevant acceptance tests are actually performed.
- Confirm any remaining open pull requests and documentation updates before submission.
