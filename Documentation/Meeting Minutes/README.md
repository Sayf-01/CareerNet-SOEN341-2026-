# Meeting Minutes

One file per meeting, named `YYYY-MM-DD <topic>.md`, for example `2026-11-19 Sprint 4 mid-sprint.md`.

To write minutes, copy `_TEMPLATE.md`, rename it, and fill it in. Write only what was said and decided. If something wasn't noted, write "not recorded" instead of guessing.

Upload the minutes the same day as the meeting: open a pull request and ask someone to review it.
